# Taskflow - SaaS Landing Page

Modern, professional SaaS landing page for a project management tool targeted at startups. Built with Next.js and Tailwind CSS.

## Features

- **Hero Section** - "Scale your startup effortlessly" headline with "Start Free Trial" CTA
- **About Section** - Describes the project management tool built for startups
- **Pricing** - 3 tiers: Free, Pro, and Enterprise
- **Features Overview** - Sprint planning, collaboration, milestones, integrations
- **Testimonials** - Social proof from startup founders
- **Signup Form** - Email capture for free trial
- **Footer** - Product, company, and legal links
- **Responsive Design** - Optimized for mobile and desktop

## Tech Stack

- Next.js 14
- React 18
- Tailwind CSS
- TypeScript

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
npm start
```
