# Writer Portfolio & Blog

A writer's portfolio website with blog as primary content. Built with Next.js, React, and Tailwind CSS.

## Features

- **Hero section** – Landing with tagline and CTAs
- **About** – Author bio and background
- **Portfolio showcase** – Featured writing projects
- **Blog** – Post listing with:
  - Search
  - Category filtering
  - Tag filtering
  - Featured images
  - Reading time estimates
- **Individual post pages** – Full articles with metadata
- **Contact form** – Get in touch
- **Footer** – Email newsletter signup
- **Dark mode** – Dark theme only
- **Responsive design** – Mobile-first layout

## Tech Stack

- Next.js 16
- React 19
- Tailwind CSS 4
- TypeScript

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Build

```bash
npm run build
npm start
```

## Project Structure

- `src/app/` – App router pages and layouts
- `src/components/` – Reusable UI components
- `src/lib/data.ts` – Blog posts, projects, author data
