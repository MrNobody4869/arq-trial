# Neo-Brutalist Portfolio

Portfolio de una página con estética neo-brutalista. Diseño moderno con tipografía audaz, alto contraste negro/blanco, acentos rojos, formas geométricas, líneas de cuadrícula visibles y elementos crudos.

## Características

- **Hero** - Encabezado impactante con llamada a la acción
- **Sobre mí** - Resumen personal y estadísticas
- **Proyectos** - Grid de proyectos con datos de ejemplo
- **Skills** - Tecnologías destacadas
- **Contacto** - Formulario y enlaces
- Diseño responsive mobile-first
- Tema neo-brutalista: cuadrícula visible, texturas crudas, formas geométricas

## Tech Stack

- React
- Next.js
- Tailwind CSS

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## Build

```bash
npm run build
npm start
```
