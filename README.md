# Flappy Bird

A web browser clone of the classic Flappy Bird game built with HTML5 Canvas.

## How to Play

- **SPACE** or **CLICK** to flap and make the bird fly upward
- Navigate through the gaps in the pipes
- Score 1 point for each pipe you pass
- Don't hit the pipes, ground, or ceiling!

## Features

- Bird character with gravity and flap mechanics
- Endless procedurally generated pipes with random gap positions
- Collision detection for pipes, ground, and ceiling
- Score tracking (1 point per pipe passed)
- Local storage for persistent high score
- Game over screen with score and high score display
- Start and restart functionality

## Run Locally

Open `index.html` directly in a web browser, or serve it with a local server:

```bash
# Python 3
python3 -m http.server 8080

# Then open http://localhost:8080
```

## Tech Stack

- HTML5 Canvas
- Vanilla JavaScript
- CSS3
