# Writer Portfolio & Blog

A professional portfolio for writers and content creators, built with Next.js and Tailwind CSS. Features client work showcase, blog articles, testimonials, and a corporate/professional design with dark mode support.

## Features

- **Project Gallery** – Client work samples with descriptions and category filtering
- **Blog** – Article listings with individual post pages
- **About** – Professional bio section
- **Contact** – Simple contact form and email option
- **Testimonials** – Client testimonial showcase
- **Dark Mode** – Toggle between light and dark themes
- **Responsive Design** – Mobile-first, works on all screen sizes

## Tech Stack

- Next.js 14 (App Router)
- React 18
- Tailwind CSS
- TypeScript

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Build

```bash
npm run build
npm start
```

## Project Structure

- `src/app/` – Pages and routing
- `src/components/` – Reusable components (Header, Footer, cards, forms)
- `src/data/` – Sample data (projects, blog posts, testimonials)

Replace sample data in `src/data/` with your own content. Connect the contact form to your preferred backend or form service.
