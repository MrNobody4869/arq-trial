# Lumina Foundation — NGO Landing Page

A luxurious, minimalist landing page for a fictional NGO built with Next.js, Tailwind CSS, Playfair Display, and Inter fonts.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Tech Stack

- **Next.js 16** (App Router)
- **Tailwind CSS 4**
- **TypeScript**
- **Google Fonts** (Playfair Display + Inter)
