# Writer Portfolio & Blog

A professional portfolio and blog for writers and content creators. Built with Next.js, React, and Tailwind CSS.

## Features

- **Project Portfolio** – Showcase client work with categories and filtering
- **Blog** – Article listing and individual post pages
- **About** – Professional bio and services
- **Contact** – Simple contact form and email
- **Testimonials** – Client testimonials section
- **Dark Mode** – Toggle between light and dark themes
- **Responsive Design** – Works on all screen sizes

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- Next.js 14 (App Router)
- React 18
- Tailwind CSS
- TypeScript

## Customization

- Edit `src/data/projects.ts` for portfolio content
- Edit `src/data/blog.ts` for blog posts
- Edit `src/data/testimonials.ts` for client testimonials
- Update contact email in `src/app/contact/page.tsx`
