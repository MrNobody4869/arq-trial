# Portfolio Neo-Brutalista

Portfolio web con diseño neo-brutalista: estética bold, bordes gruesos y esquema de colores negro/blanco/rojo.

## Características

- **Hero Section** - Presentación impactante con animaciones
- **Sobre Mí** - Sección acerca del desarrollador
- **Proyectos** - Grid de proyectos destacados
- **Habilidades** - Stack tecnológico organizado por categorías
- **Testimonios** - Opiniones de clientes
- **Formulario de Contacto** - Para enviar mensajes

## Tecnologías

- Next.js 16
- TypeScript
- Tailwind CSS v4

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## Build

```bash
npm run build
npm start
```

## Estética Neo-Brutalista

- Bordes negros gruesos (4px)
- Esquema de colores: negro (#0a0a0a), blanco (#ffffff), rojo (#e63946)
- Sombras offset que replican los bordes
- Tipografía bold (Archivo Black, Space Grotesk)
- Animaciones de scroll e interacciones hover
